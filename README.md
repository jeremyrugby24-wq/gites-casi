# Gîtes CASI

[Ouvrir la carte interactive](https://jeremyrugby24-wq.github.io/gites-casi/)

Comparatif personnel de 27 configurations de logements et 49 offres du CASI, relevées le 25 novembre 2026.

- Carte vectorielle avec zoom et déplacement.
- Ville, capacités et tarifs au survol ; fiches dans le panneau latéral.
- Stations de ski proches avec pictogrammes bleus et liens vers les informations officielles.
- Filtres par destination, équipement, capacité et catégorie.

Les tarifs et disponibilités sont indicatifs et doivent être confirmés auprès du service Locations du CASI. Les repères sont approximatifs ; les distances des stations sont à vol d’oiseau et ne constituent pas un itinéraire routier. Ce comparatif personnel n’est pas un site officiel du CASI.

## Hébergement

Page statique `index.html`, publiée depuis la branche `main` avec GitHub Pages. Le fond haute définition utilise MapLibre et OpenFreeMap ; les données cartographiques proviennent d’OpenStreetMap / OpenMapTiles. Un fond raster intégré sert de secours.
